Station 3 action math, from teleop to the follower command

How one action is represented at every step: absolute joints in the dataset, delta joints for ACT, ACT's z-score, the RL min-max space, and back to an absolute joint target. Joint 2 is followed through with real numbers. Every number is taken from the dataset, the step-70016 checkpoint or the eval logs.

Three places where the code differs from the usual mental model

The RL action space is min-max, not z-score. ActionScaler reads only the dataset action min and max. The action mean and std are what ACT uses, and the RL never reads them.
stddev_max / stddev_min are not statistics. They set the width of the exploration noise added to the actor's output during training (and to the critic's target action). They play no part in the scaler.
The residual is added in normalized space, then unscaled once. The code computes unscale(clip(base_n + r)). Without clipping this equals ACT's real delta plus r · half_exp, checked to 5e-8 on 6,828 eval ticks. action_scale appears twice: it widens the box (he = half · (1 + s)) and it caps the residual (|r| ≤ s).
