## 🔧 Architecture

```
Input: Robomimic HDF5
  ↓
Conversion (parallelized)
  ↓
Try: LeRobotDataset.push_to_hub()
  ├─ ✅ Success → Done!
  └─ ❌ Error → Fallback
      ↓
      Salvage Upload:
      • Fix paths
      • Create repo + tag
      • Direct upload
      • Generate README
      ↓
      ✅ Dataset on Hub!
```

## ❓ Troubleshooting

### YAML warning still visible?
→ Run: `python update_readme_only.py --output_dir ... --repo_id ...`

### Upload stuck?
→ Check: `huggingface-cli status`

### Out of space?
→ Clean: `rm -rf ~/.cache/huggingface/lerobot/*/tmp*`

### Connection issues?
→ Check: `huggingface-cli login` and network
